# Method and data references

Baseline labels identify adaptations to the gap-constrained temporal-walk task; they do not denote unmodified upstream executables.

- PathEnum: Sun et al., *PathEnum: Towards Real-Time Hop-Constrained s-t Path Enumeration*, SIGMOD 2021. https://arxiv.org/abs/2103.11137 and https://github.com/Xtra-Computing/PathEnum.
- CPE: Zhang et al., *Hop-Constrained s-t Simple Path Enumeration on Large Dynamic Graphs*, ICDE 2023. https://fanzhangcs.github.io/papers/2023_icde_simplepath.pdf.
- TSPG: Tang et al., *Efficient Temporal Simple Path Graph Generation*. https://arxiv.org/abs/2507.10017.
- SNAP temporal datasets and source references: https://snap.stanford.edu/temporal-motifs/data.html.
- KONECT dataset collection: https://konect.cc/.
- ORBITAAL: https://zenodo.org/records/12581515.

Prepared graph inputs are identified by the hashes in the artifact manifest.
